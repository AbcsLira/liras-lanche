# 🍔 Cartão Interativo — Lira's Lanche

> Um cartão digital interativo desenvolvido para facilitar o acesso dos clientes às principais informações e canais de atendimento da **Lira's Lanche**.

## 📌 Sobre o projeto

O **Cartão Interativo do Lira's Lanche** foi desenvolvido como uma alternativa moderna aos tradicionais cartões de visita impressos.

A proposta é reunir, em uma única interface, as principais informações da empresa, permitindo que o cliente encontre rapidamente os canais de contato, localização e acesso ao site.

O projeto foi pensado com foco em **simplicidade, responsividade e experiência do usuário**, funcionando tanto em computadores quanto em dispositivos móveis.

## ✨ Funcionalidades

* 📱 Interface responsiva para celulares, tablets e computadores
* 📞 Acesso rápido aos números de telefone
* 🌐 Link direto para o site da empresa
* 📍 Informações de localização
* 🍔 Apresentação dos principais produtos e serviços
* 🔗 Botões interativos para facilitar a navegação
* 🎨 Interface moderna e visualmente agradável
* 📲 QR Code direcionando para o cartão/site
* ⚡ Estrutura leve e de carregamento rápido


## 🛠️ Tecnologias utilizadas

* **HTML5** — estrutura da aplicação
* **CSS3** — estilização, responsividade e layout
* **QR Code** — acesso rápido através de dispositivos móveis


## 🎯 Objetivo

O projeto teve como objetivo transformar uma experiência tradicional de apresentação de uma empresa em uma solução **digital, acessível e interativa**.

Além de servir como cartão digital, o projeto demonstra conhecimentos em:

* Desenvolvimento Front-End
* HTML semântico
* CSS responsivo
* UI/UX
* Design de interfaces
* Responsividade
* Organização de projetos
* Criação de soluções digitais para negócios reais

## 📱 Responsividade

A interface foi desenvolvida pensando principalmente na experiência mobile, já que o cartão pode ser acessado diretamente pelo celular através de um QR Code.

O layout se adapta a diferentes tamanhos de tela, mantendo a navegação simples e os principais contatos sempre acessíveis.

## 🚀 Como executar

Você pode executar o projeto localmente de forma simples:

```bash
# Clone o repositório
git clone https://github.com/AbcsLira/liras-lanche

# Acesse a pasta
cd cartao-interativo
```

Depois, basta abrir o arquivo `index.html` no navegador.

Também é possível utilizar extensões como **Live Server** no VS Code para visualizar o projeto durante o desenvolvimento.
